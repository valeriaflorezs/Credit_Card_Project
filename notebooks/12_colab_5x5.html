12. Corrida 5 x 5 en Colab (todos los modelos con el mismo código)#

Este notebook repite las combinaciones con validación cruzada anidada de 5 folds externos y 5 internos usando exactamente el código de src/ del proyecto (experiment_runner.run_experiments), no una copia. Así todos los modelos, incluido SVM con sklearn.svm.SVC, se evalúan con el mismo solver y las mismas librerías.

Cómo repartir el trabajo. Todas las sesiones corren las 4 técnicas de balanceo (none, smote, adasyn, class_weight), como pide el diseño del entregable. Lo que se reparte entre sesiones son los modelos y los métodos de optimización (MODELS y METHODS, celda 1). Cada sesión guarda su propio CSV en Drive, así varias sesiones en paralelo no se pisan. El costo medido de la corrida 3 x 3 era KNN 8.6 h, Random Forest 3.3 h, XGBoost 1.1 h, regresión logística 0.5 h, árbol 0.1 h y Naive Bayes 0.1 h, y con 5 x 5 se espera unas 4 veces más. En la corrida real, Colab (T4 con cuML) solo ejecutó KNN y SVM (32 combinaciones); las otras 80 se corrieron en la PC.

models = [MODEL_REGISTRY[m] for m in MODELS]
tag = "-".join(MODELS) + "__" + "-".join(METHODS)
CHECKPOINT = OUT_DIR / f"experiments_5x5__{tag}.csv"

nj = config.OPTIMIZATION_N_JOBS
optimizer_kwargs_by_method = {
    "grid_search": {"n_jobs": nj},
    "random_search": {"n_iter": config.RANDOM_SEARCH_ITER, "n_jobs": nj},
    "bayesian_optuna": {"n_trials": config.OPTUNA_N_TRIALS, "n_jobs": nj},
    "genetic_deap": {"population_size": config.GA_POPULATION_SIZE, "n_generations": config.GA_N_GENERATIONS, "n_jobs": nj},
}
combos = get_all_combinations(models, TECHNIQUES, METHODS)
assert set(TECHNIQUES) == {"none", "smote", "adasyn", "class_weight"}, "cada sesión debe usar las 4 técnicas"
print(f"{len(combos)} combinaciones en esta sesión -> {CHECKPOINT}")
