Reproducibilidad, archivo del repositorio y declaración de autoría#

Lista de verificación de reproducibilidad#

Elemento

Detalle

Código

https://github.com/valeriaflorezs/Credit_Card_Project (licencia MIT)

Archivo con identificador persistente

DOI de Zenodo: pendiente de completar con el DOI de la release v3.0.0

Datos

UCI Default of Credit Card Clients (CC BY 4.0); ver DATA_STATEMENT.md

Semilla global

42 (src/config.py), usada en particiones, búsquedas y modelos

Validación

Anidada estratificada, 5 pliegues externos × 5 internos

Ejecuciones

Una corrida por combinación; dispersión reportada como desviación estándar entre pliegues (ddof=1)

Rangos de hiperparámetros

src/models.py (MODEL_REGISTRY), uno por modelo

Presupuesto de búsqueda

Malla ≤ 200 combinaciones, 25 aleatorias, 30 de Optuna, genético 16 × 10 (src/config.py)

Software

Python 3.12, numpy 2.5.3, pandas 3.0.6, scikit-learn 1.9.1, xgboost 3.4.1, lightgbm 4.7.0, catboost 1.2.10, optuna 5.0.0, deap 1.4.3 (requirements.txt)

Hardware

Windows, AMD Ryzen 7, 16 GB de RAM, sin GPU (modelos de árboles, CS-FOF y boosting); Google Colab con GPU T4 (SVM y KNN)

Tiempo de cómputo de CS-FOF

Malla 2.7 h, aleatoria 2.5 h, Optuna 2.5 h y genético 9.6 h (5 × 5, 8 procesos)

Pruebas automáticas

python -m pytest tests/ -q (14 pruebas) en GitHub Actions en cada push

Modelo final

python -m src.train_cs_fof_artifact → artifacts/cs_fof.joblib y artifacts/metadata.json

Corridas

python -u -m src.run_cs_fof_5x5 class_weight y python -u -m src.run_boosting_recientes_5x5 --tecnicas class_weight --metodos grid_search random_search bayesian_optuna

Conjuntos adicionales

python -u -m src.run_additional_datasets (descarga German, Australian y Polish con ucimlrepo)

Tabla maestra y pruebas

python -m src.build_master_table_e3, luego python experiments/comparacion_final/pruebas.py, delong.py y entre_conjuntos.py

Robustez (exploratoria)

python experiments/robustez/robustez.py (calibración, ruido y tamaño de muestra; ~1 h en 4 núcleos)

Evaluación ampliada (exploratoria)

python experiments/robustez/ampliada.py (diagrama de diferencia crítica, predicción conforme, recalibración, análisis de errores, cambio de distribución, escalabilidad y 10 semillas; ~35 min en 4 núcleos)

Validación del genético (De Jong)

python -m src.dejong (5 funciones, 10 semillas, presupuesto del proyecto y 50 × 50; unos 2 min)

Protocolo

experiments/protocolo.md, registrado el 8 de noviembre de 2026 en el commit 62ddeb7 (etiqueta protocolo-2026-11-08)

Declaración de autoría y uso de herramientas#

Este trabajo fue realizado por Valeria Florez Sarmiento y Katherin Barrera López, quienes contribuyeron de manera conjunta al diseño, la ejecución de los experimentos, el análisis y la redacción.

Durante el proyecto se utilizó la herramienta de inteligencia artificial generativa Claude (Anthropic) como apoyo en la búsqueda bibliográfica, la programación (incluida una implementación de referencia del modelo original y sus pruebas), el análisis estadístico, la redacción, el desarrollo del dashboard en Dash y de su versión en Shiny, y la generación de los artefactos de los modelos. Todo el contenido generado con apoyo de la herramienta fue revisado, verificado y editado por las autoras, quienes comprenden el código entregado, pueden explicarlo y modificarlo, y asumen la total responsabilidad por el contenido, los análisis y las conclusiones de este informe. La herramienta no figura como autora.
